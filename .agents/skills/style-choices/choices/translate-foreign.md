---
name: translate-foreign
description: Lines in a chosen language kept as spoken, with a translation added.
section: Language
---

## Ask

1. Which language gets a translation? For example Spanish. *Required.*
2. Translate into what? English (default), your main language, or both.
3. How should it show? A smaller second line under the original (default), or the
   translation in place of the original.

## Write

- When I speak {language}, {keep it as spoken and add the {target} translation as a
  smaller second line under it | show the {target} translation in its place}.

## Conflicts

- A rule to never translate. If the user keeps the choice, keep that rule and add
  the exception ("never translate, except {language} as below") rather than
  removing it.

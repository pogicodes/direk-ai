name: quiet-voice
description: Quiet or whispered lines shown in smaller caption text, with no "(whispers)" labels.
section: Captions

## Ask

1. How much smaller? Slightly (default) or noticeably.

## Write

- Low/soft voice (whispering, speaking quietly): measure loudness per phrase and
  show quiet lines in {slightly|noticeably} smaller text. No "(whispers)" labels.
  Still readable.

## Conflicts

- A rule that every caption is the same size. If the user keeps the choice, add
  "except quiet lines" to it.
- Tone labels in captions, like "(whispers)" or "(pabulong)". If the user keeps the
  choice, remove the labels.

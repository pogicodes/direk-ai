## Ask

1. Who else speaks in your videos? A name and who they are for each, e.g. "Sam,
   my partner", "Mia, my 5-year-old daughter". *Required.*
2. A color for each person? Default: you = white (#FFFFFF), others in order: soft
   pink (#FFA3CF), light purple (#C9A6FF), soft yellow (#FFE27A), mint (#8FF0C8),
   light blue (#9CD3FF). Any color you pick must be light enough to read on a dark
   box.
3. Anything that helps tell voices apart? For example "my voice can rise to
   ~200–260 Hz, close to Sam's". Default: none.

## Write

- Color by speaker (text color only, same dark box): me = {my color name}
  ({my hex}), {name} ({who}) = {color name} ({hex}), …. Tell speakers apart by
  voice pitch and context; list any lines you are unsure of in the draft summary.
- [Speaker notes: {voice notes}.]
- Every caption must stay readable: keep the dark box behind all colors, never use
  dark or low-contrast shades.

## Conflicts

- Captions with no dark box behind the text (shadow only, outline only): colored
  text needs the box to stay readable. If the user keeps the choice, change that
  bullet to a dark box.
- A rule that every caption uses one color no matter who speaks, or key-word
  highlight colors that reuse a speaker's color. If the user keeps the choice,
  remove the one-color rule, or give the highlight a color no speaker uses. A plain
  "white text" caption bullet is no clash: it is the user's own color.

## Also

- Add each speaker's name to `profile/vocabulary.md` if it is missing.
